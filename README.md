# Wine Quality Prediction

Machine learning project to predict wine quality using physicochemical features.

## Overview
This project uses a structured dataset to train a model that predicts wine quality based on various input features.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Approach
- Data loading and exploration  
- Feature analysis and selection  
- Model training 
- Model evaluation
